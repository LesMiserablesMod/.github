# LesMiserablesMod 组织配置 / Organization Configuration

本仓库维护 LesMiserablesMod 的公开组织主页和默认社区模板。

This repository maintains the public organization profile and default community templates for LesMiserablesMod.

- [`profile/readme.md`](profile/readme.md)：公开组织主页 / public organization profile
- [`.github/ISSUE_TEMPLATE`](.github/ISSUE_TEMPLATE)：默认 Issue 表单 / default issue forms
- [`.github/PULL_REQUEST_TEMPLATE.md`](.github/PULL_REQUEST_TEMPLATE.md)：默认 PR 模板 / default pull request template

MOD 的明确 Bug 请提交到本仓库的 [Issues](https://github.com/LesMiserablesMod/.github/issues)；玩法建议、世界观讨论和平衡意见请使用组织 [Discussions](https://github.com/orgs/LesMiserablesMod/discussions)。工具相关问题请提交到对应工具仓库。

Use this repository's [Issues](https://github.com/LesMiserablesMod/.github/issues) for concrete mod bugs. Use organization [Discussions](https://github.com/orgs/LesMiserablesMod/discussions) for ideas, lore, and balance feedback. Report tool-specific problems in the relevant tool repository.
